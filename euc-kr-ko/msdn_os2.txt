OS2.TXT

한글 MS-DOS 6으로 업그레이드시 참고 사항
========================================

OS/2를 사용 중이고 마이크로소프트 한글 MS-DOS 6
사용자 설명서에서 OS2.TXT 파일을 참고하라고 하면
아래의 내용에서 사용 중인 컴퓨터의 구성에 맞는
과정을 수행하면 된다.

참고: OS/2 이중 부트의 몇몇 버전에서는 메뉴 시스템을 사용한다. 명령
프롬프트에서 작동하는 버전도 있다. 사용 중인 버전이 메뉴 시스템으로 되어
있으면 설치 프로그램은 이중 부트를 사용 불능으로 만든다. 사용 중인 버전이 명령
프롬프트에서 작동하는 것이고 하드 드라이브에 MS-DOS가 있으면 설치 프로그램은
이중 부트를 없애지 않는다. 사용 중인 버전이 명령 프롬프트에서 작동되는 것이지만
하드 드라이브상에 MS-DOS가 없는 경우에는 OS/2 설명서에서 같은 컴퓨터에
OS/2와 MS-DOS를 설치하는데 대한 설명을 본다.

OS/2 이중 부트나 OS/2 부트 관리자 모두가 없을 때
------------------------------------------------
OS/2를 컴퓨터에서 제거하려고 하지만 하드디스크의
데이터를 먼저 저장하고자 하는 경우 다음 과정을
수행하도록 한다.

컴퓨터의 데이터를 저장하고 OS/2를 제거하는 방법

1. OS/2를 사용하여 컴퓨터를 재시동한다.

2. COPY 명령을 사용하여 저장하고자 하는 데이터 파일을
   플로피디스크로 백업한다.

   주의: OS/2 시스템 파일을 하드디스크에서 삭제하지 않도록 주의한다.

3. 설치 디스크를 A 드라이브 (시동 드라이브)로 다시 삽입한다.

4. CTRL+ALT+DEL을 눌러 컴퓨터를 재시동한다.

5. 설치 프로그램이 화면에 비 MS-DOS 분할이나 비 MS-DOS 파일에
   관해 표시해주면 분할이나 파일을 제거하는 것으로 선택한다.

6. MS-DOS의 설치가 완료된 후에 단계 2에서 저장했던
   데이터 파일을 플로피 디스크에서 하드디스크로 복사한다.

DOS와 OS/2 이중 부트 혹은 DOS와 OS/2 부트 관리자가 있는
있는 경우
-------------------------------------------------------
설치 프로그램이 OS/2를 검색해 내면 화면에 "비 MS-DOS 분할이
검색되었습니다" 혹은 "OS/2 파일이 검색되었습니다" 라고 표시해준다.
설치 프로그램이 "비 MS-DOS 분할이 검색되었습니다" 란 표시를 하면
과정 1을 수행한다. 설치 프로그램이 "OS/2 파일이 검색되었습니다" 를
화면에 표시하면 과정 2를 수행한다.

과정 1 : OS/2를 제거하고 컴퓨터의 데이터를 저장하는 방법

1. 설치 프로그램이 "비 MS-DOS 분할이 검색되었습니다" 라고 화면에
   표시하면 "설치 계속" 옵션을 선택한다.

2. MS-DOS 6을 설치한 후에, 하드디스크를 사용할 수 있는지
   확인해 본다.

3. 저장하고자 하는 데이터 파일을 플로피 디스크나 네트워크
   드라이브로 백업한다.

4. "문제점 진단과 해결" 이라는 장에 있는 "Fdisk를 사용하여
   하드디스크 구성하기"를 보고 다음 절에 나오는 모든 과정을
   수행하도록 한다.

   o "시동 디스크 만들기"

   o "Fdisk의 사용"

   o "비 MS-DOS 분할영역의 삭제"

   o "논리 드라이브의 삭제"

   o "확장 MS-DOS 분할영역 삭제하기"

   o "기본 MS-DOS 분할영역 만들기"

   o "하드디스크 포맷하기"

5. 설치 프로그램을 재시동한다. 이를 위해서는 설치 디스크
   1번을 A 또는 B 드라이브로 넣고 명령 프롬프트에서 다음을
   입력한다.

   A:SETUP

   혹은

   B:SETUP

6. 하드디스크를 구성한 후에, 단계 3에서 저장했던 파일을
   디스크로 다시 복사한다.

과정 2 : OS/2를 제거하고 컴퓨터의 데이터를 저장하는 방법

참고: 버전 2.0이 아닌 다른 버전의 OS/2를 갖고 있으면
하드디스크의 OS/2 파일과 디렉토리의 이름이 이 과정에
나오는 이름과 다를 수도 있다.

주의: MS-DOS 프로그램 파일을 컴퓨터에서 삭제하지 않도록 한다.

1.  저장하고자 하는 데이터 파일을 플로피 디스크나 네트워크
    드라이브로 백업한다.

2.  설치 디스크가 A 드라이브와 호환이 되면, 설치 디스크 1번을
    A 드라이브로 삽입하고 CTRL+ALT+DEL을 눌러 컴퓨터를 재시동한다.
    설치 프로그램이 첫번째 화면을 보여주면 그 다음에 F3키를 두번
    눌러 설치 프로그램을 종료한다.

    설치 디스크가 A 드라이브와 호환이 안되면, A 드라이브에
    맞는 시동 플로피 디스크를 만든다. 이를 위해서는 설치
    디스크 1번을 B 드라이브에 넣고 명령 프롬프트에서 다음을
    입력한다.

    B:SETUP /F

    프롬프트가 나오면 한글 MS-DOS를 A 드라이브에 들어 있는
    플로피 디스크에 설치하도록 선택한다. 설치 과정이 끝나면,
    A 드라이브에 시동 디스크를 그대로 두고 CTRL+ALT+DEL을
    눌러 컴퓨터를 재시동한다.

3.  명령 프롬프트에서 다음을 입력하여 C 드라이브를 현재 드라이브로
    만든다.

    C:

4.  한번에 하나씩 CD 명령을 사용하여 각각의 OS/2 디렉토리와
    하위 디렉토리를 현재 디렉토리로 만들어 DEL 명령으로 안에
    있는 파일을 모두 삭제한다. 예를 들어, OS2 디렉토리의
    SYSTEM이란 하위 디렉토리를 현재 디렉토리로 만들고 그 안의
    모든 파일을 삭제하려면 명령 프롬프트에서 다음을 입력한다.

    CD \OS2\SYSTEM
    DEL *.*

5.  이런 하위 디렉토리에서 모든 파일을 삭제한 후엔 RD 명령을
    사용하여 하위 디렉토리를 삭제한다. 예를 들어, C 드라이브에
    있는 OS2 디렉토리에서 SYSTEM 이란 하위 디렉토리를 삭제하려면
    다음을 입력한다.

    RD C:\OS2\SYSTEM

6.  OS/2, PSFONTS, SPOOL, NOWHERE, 그리고 OS!2_2.0_D에 있는
    모든 하위 디렉토리를 삭제한 후에는 DEL 명령을 사용하여
    이들 디렉토리에 있는 파일을 삭제한다.

7.  RD 명령을 사용하여 OS2, PSFONTS, SPOOL, NOWHERE, 그리고
    OS!2_2.0_D 디렉토리를 삭제한다.

8.  다음을 제외한 루트 디렉토리의 모든 OS/2 파일을 다른 디스크나
    디렉토리로 이동한다.

    EA DATA.SF
    OS2lDR.MSG
    OS2lDR
    OS2KRNl
    OS2BOOT
    WP DATA. SF

9.  명령 프롬프트에서 다음을 입력하여 루트 디렉토리로 간다.

    CD\

10. 명령 프롬프트에서 다음을 입력하여 단계 8에서 나열된
    다섯개 파일의 속성을 변경한다.

    A:\ATTRIB -H -S -R C:\E*.*
    A:\ATTRIB -H -S -R C:\O*.*
    A:\ATTRIB -H -S -R C:\W*.*

11. 명령 프롬프트에서 다음을 입력하여 속성이 변경된 파일들을
    삭제한다.

    DEL E*.*
    DEL O*.*
    DEL W*.*

12. 단계 8에서 이동한 파일을 루트 디렉토리로 다시 이동한다.

13. 플로피 디스크 드라이브에 있는 모든 디스크를 제거하고
    CTRL+ALT+DEL 키를 눌러 컴퓨터를 재시동한다.

14. A 또는 B 드라이브에 설치 디스크 1번을 삽입한다.

15. 명령 프롬프트에서 다음을 입력하여 설치 프로그램을 다시 실행시킨다.

    A:SETUP

    혹은

    B:SETUP

DOS 없이 OS/2 부트 관리자만 있는 경우
-------------------------------------

OS/2를 제거하고 하드디스크의 데이터를 저장하는 방법

1. 저장하고자 하는 데이터 파일을 COPY 명령을 사용하여
   플로피디스크나 네트워크 드라이브로 백업한다.

2. 설치 디스크 1번을 A 드라이브(시동 드라이브)로 다시 삽입한다.

3. CTRL+ALT+DEL 키를 눌러 컴퓨터를 재시동한다.

4. 설치 프로그램이 OS/2나 비 MS-DOS 파일에 관해 화면에
   표시해주면 OS/2나 그런 파일을 제거하는 것으로 선택한다.

5. MS-DOS의 설치 작업이 완료되면 단계 1에서 저장한 데이터
   파일을 하드디스크로 복사한다.
