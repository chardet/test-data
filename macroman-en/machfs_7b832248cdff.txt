This setting will work on computers with as little as 4 MB of RAM. If you have a computer with 8 MB or more, you may want to increase the Preferred Size (to 5000 KB, for example). Increasing the Preferred Size will give Widget Workshop more memory so you can build bigger widgets. To increase the Preferred Size: 		1. Single-Click on the Widget Workshop icon in the finder.		2. Open the File menu and select Get Info to open the Information window.		3. Highlight the number 2400 in the box next to the words "Preferred size."		4. Type in a new number (5000).		5. Close the Information window.¥ Recorders use the most memory. If you run out of memory and need some other parts, cut out some Recorders. After Recorders, the other sound parts use the most memory.¥ Stand-alone widgets can be very big. They can even be too big to fit on a floppy disk unless you first compress them using some sort of data compression program.GAMEPLAY¥ Widget Workshop will run faster if you install it on your hard drive. You can do this if you are running System 7 or above and if you can (and want to) spare 8 MB of hard drive space.¥ Keyboard Equivalents:	GO:   Enter key 	STOP:   Esc key	Cut Tool:   Option key	Move Tool:   Ctrl key	Delete:   Delete key (not the del-with-an-X)¥ There are no Scroll Bars.¥ If you save a puzzle, it will be saved as a regular widget--and the one on the screen will automatically become a regular widget. You can solve it, but it wonÕt be marked as solved in the Load Puzzle dialog box. If you want to solve a puzzle and have it marked solved, you have to do it in one sitting--without saving.¥ The sounds that you record in the Recorder will play back at a fairly low sound volume.¥ If you want to start Widget Workshop quickly, just double-click on a "blank" saved widget (if you want to start up with a blank Work Area), or on any saved widget for that matter.PRINTING¥ Here are two settings that may improve print quality for widgets:In the Page Setup option from the File menu, choose  Landscape orientation (the right-hand one of the two Orientation icons).In the Print dialog box, choose "Color/Grayscale" instead of "Black&White" before you click on Print.SYSTEM INFO/CONFLICTS¥ Sometimes errors occur when saving stand-alone widgets under System 7.5.1. Please contact Maxis Technical Support if you have this problem.¥ Included on the CD is a "system extension" called Sound Manager 3.0, written by Apple Computer.  While not absolutely required for most users, it is a good thing to have in your System Folder, and some users may have trouble starting or running Widget Workshop unless Sound Manager is present. So please keep drop it in your system folder if you are having any problems with your sound.¥ The Apple "32-Bit QuickDraw" routines are needed in order to allow Widget Workshop to run properly. If you have a Mac IIci or a later Macintosh model that has "32-Bit QuickDraw" in ROM, this note won't apply to you. If you have an earlier model, 32-Bit QuickDraw is a file that should be on one of the System Software disks that came with your computer, and it must be installed before Widget Workshop will be able to run.¥ We have found that the ColorMaster extension (version 1.2.1) can cause the wrong cursor to appear in part dialog boxes after you save a stand-alone widget. This may also be a caused by other extensions you may have that change and/or colorize the cursor. You can turn off the conflicting extension if you'd like, but you should be able to reset the cursor by just moving the mouse up to the menu bar and back down to the Work Area.
